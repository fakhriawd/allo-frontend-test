# SpaceX Rocket Explorer 

Simple web app built with React & Vite to explore SpaceX rockets. Made as part of the frontend technical test for Allo Bank.

## Features Included
- **Rocket List Screen**: Displays all SpaceX rockets fetched directly from the API (complete with image, name, and description).
- **Search & Filter**: Real-time filtering to search rockets by their name easily.
- **Add Custom Rocket**: A modal form to add a new local rocket on the fly (since the API is read-only).
- **Rocket Detail Screen**: Detailed view showing specific attributes like launch cost, country, and first flight date.

## Tech Stack
- React / Vite
- JavaScript (ES6+)
- Launch Library 2 API (`/2.2.0/config/launcher/`)

## How to Run Locally

1. Clone or fork this repo.
2. Install dependencies:
   npm install
3. Run in cmd:
    npm run dev
4. Open Localhost:5173 in browser
